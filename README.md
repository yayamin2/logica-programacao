## 🧰 Minha cola rápida

<details>
<summary><b>O que aprendi a olhar quando algo dá errado</b></summary>

- A **identação** (espaços) está certa? Em Python, blocos dependem do recuo correto.
- O valor que veio do `input()` é texto (`str`) ou precisa virar número (`int` / `float`)?
- O `print` ou a atualização de variável está **dentro ou fora** do loop?
- Leio o código em português: se a frase faz sentido, a lógica provavelmente está no caminho certo.

</details>

<details>
<summary><b>Moldes que mais uso</b></summary>

# entrada e saída básica
nome = input("Digite seu nome: ")
print(f"Olá, {nome}!")

# condicional simples
if condicao:
    print("Verdadeiro")
else:
    print("Falso")

# repetição com contagem
for i in range(5):
    print(i)
